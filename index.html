Key Feature 1: CSS Grid for 2D Layouts

CSS Grid coordinates both rows and columns simultaneously. In this project, we designed a 12-column Bento Grid for the featured projects showcase where cards span 7, 5, or 6 columns with harmonious negative space, plus auto-fit responsive tracks for credentials.

.projects-bento-grid { display: grid; grid-template-columns: repeat(12, 1fr); gap: 26px; } .bento-span-7 { grid-column: span 7; } .bento-span-5 { grid-column: span 5; } .bento-span-6 { grid-column: span 6; }

Key Feature 2: Flexbox for Localized Alignment

Flexbox is used for single-axis flow and component-level alignment: centering hero content, distributing navigation items with justify-content: space-between, and wrapping technology tags with flex-wrap: wrap; gap: 8px;.

.project-tags { display: flex; flex-wrap: wrap; gap: 8px; align-items: center; } .nav-container { display: flex; justify-content: space-between; align-items: center; }

Key Feature 3: Mobile-First Responsive Media Queries

Media queries are designed with progressive enhancement: mobile base styles (<480px), transitioning to phablets (480px), tablets (768px), laptops (1024px), and widescreen monitors (1440px). All Bento spans collapse safely to grid-column: span 12 on mobile devices.

@media screen and (max-width: 1024px) { .bento-span-7, .bento-span-5, .bento-span-6 { grid-column: span 12; } } @media screen and (max-width: 768px) { .skills-grid { grid-template-columns: 1fr; } .certificates-grid { grid-template-columns: repeat(2, 1fr); } }

Key Feature 4: CSS Custom Variables Theme Engine

CSS custom properties (--primary, --bg-primary, --text-main) enable instant zero-reload theme switching, smooth transitions, and multi-palette customization without touching stylesheet files.

:root { --primary: hsl(var(--primary-h), var(--primary-s), var(--primary-l)); --bg-primary: #f8fafc; --text-main: #0f172a; } [data-theme="dark"] { --bg-primary: #0a0f1d; --text-main: #f8fafc; }
